## 实现边界

- 普通 UI 初始化、切会话、刷新、翻页、筛选只请求 metadata 与 `getSessionPage`。metadata/list/选择响应没有 records/edges/rootIds。保留显式 legacy `getSessionDetails` 全量兼容 API，其手动调用仍有完整会话成本；普通界面探针没有调用它。没有现存导出 UI，未新增导出。
- 节点按 timestamp 降序、ID 升序稳定排序，全会话先过滤再分页；八项过滤共用同一判定及 tracking 关键词。一次 readonly transaction 读节点页和相关边，node limit 硬上限500，edge limit=min(2000,nodeLimit×4)，界面显示实际限制和节点/边范围。页外父节点只在渲染副本升根，详情继续显示原 parentId；页外关系不绘制，同页稠密关系可独立翻边页。
- IndexedDB v2→v3 同 upgrade transaction 为旧 node/edge 回填覆盖键；保留原 ID/字段，独立 stores 优先，旧 session 内嵌独有记录导入后再投影 metadata。缺失或超 Date 范围时间显示“未知”，不伪造小时统计；合法 epoch0 可渲染。
- page 查询流式扫描覆盖 key，只有当前页 node 与边才 get values。全局统计按 domain/url 有序 key 流式分组，24小时桶和 top10 常量集合，仅为标题读最多10 node。UI 只保留当前页；generation 在处理/通知之前拒绝旧 session/filter/page 响应。
- 冷启动无快照恢复仅按 session/tab/url 排序索引取最新1条；有快照仍按每tab最多50 IDs恢复。retention 流式过期 keys、父索引修受影响 child、source/target/timestamp keys 删边，无过期时不读完整 graph values。consistency 和 tab close 扫未关闭覆盖 keys，仅读取需更新 node；不会数组化完整会话。

## 限制与未执行范围

key过滤计数/深页offset可能每次 O(session nodes)，边范围计数可能扫描所选source的全部候选边；夹紧页可能重扫。内存与响应中物化的graph values有界，不等于DB工作量恒定。metadata精确count是索引count；多会话列表仍逐会话count。新增覆盖索引增加磁盘和写入成本，未量化。升级一次性cursor回填所有旧值，与正常page路径不同。

偏移页不是跨请求冻结快照，实时插删会移动边界；刷新重载并夹紧/重置页。静态全页可达已经验证。少量选中node payload本身长度未以本次改动重新限定；未做heap profiler、整日CPU/电量、海量真实历史磁盘压测。显式legacy全图API与未使用的legacy closeAllNodesInSession helper仍保留旧全量实现（未发现实际caller），不表示endSession会调用它；手动调用该helper仍有会话规模成本，不作为普通图页按需加载收益。

原defaultView应用只是日志以及URL.view/popstate路由的已有缺口，本轮未修也未宣称验收；已验收的是切换交互、保存值、session记忆和URL筛选重开。没有全浏览器history路由验收。最低Chrome/Node矩阵未跑。测试夹具的调试附件不长期保存。
